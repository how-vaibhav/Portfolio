## ✦ The Dual-World Architecture

This portfolio operates as two completely distinct, interconnected experiential dimensions built on a shared reactive routing spine with zero layout flicker:

| Experience Dimension | Route | Aesthetic Persona | Core Highlights & Engineering Feats |
| :--- | :--- | :--- | :--- |
| **Developer Mode** | `/` | Cyber-Industrial, Obsidian & Neon Lime (`#CCFF00`) | Pixel Image Grid Reveal, Dual-Direction Infinite Tech Marquee, Fixed Bottom Reveal Footer, 30+ DevTools Stack, Spring Physics |
| **Design Mode** | `/design` | Seamless Obsidian Studio Grid, Laser Cobalt & Saffron Accents | The Anatomy of HowVaibhav, 35-Plate Kala Mandal Dual-Orbit Wheel, Tactile Origin Story Polaroids, Kinetic Mixed-Media Assemblage |

Seamless, cinematic cross-mode navigation is orchestrated by `ModeTransitionContext` and the hardware-accelerated `ModeTransitionOverlay` with instant procedural audio warp triggers.

## 🎨 Design Mode Deep Dive (`/design`)

### 1. The Anatomy of HowVaibhav (Interactive Typography Hero)
An homage to Swiss editorial specimen posters and anatomical typography guides:
- **7-Letter Acrostic Taxonomy:** Each letterform reveals an editorial craft principle whose title spelling organically starts with that exact letter:
  - **`H`** — *Hierarchy & Height*
  - **`O`** — *Optical Balance & Orbit*
  - **`W`** — *Weight & White Space*
  - **`V`** — *Vector Craft & Volume*
  - **`A`** — *Architecture & Apex*
  - **`I`** — *Identity & Ink Precision* (featuring a pulsing cyan laser tittle)
  - **`B`** — *Baseline & Bold Stems*
- **Precision Laser Coordinate Guides:** Vector connection lines anchor dynamically to letter stems and naturally flow into hovering specimen cards without crossing paths.
- **60fps Gyro & Parallax Tracking:** Real-time mouse cursor and touch tracking with hardware-accelerated `perspective(1000px) rotateX() rotateY()` and a dynamic holographic specular glare overlay.
- **Touch-Native Mobile Specimen Deck:** Responsive horizontal snap ribbon allowing mobile visitors to swipe through all principles with zero gesture conflict.

### 2. The Origin Story & What's Up (`HowVaibhavStory.jsx`)
- **Tactile Washi-Tape Polaroids:** Analog photo showcase featuring authentic portrait photography pinned with textured semi-transparent washi tape and realistic dropshadows.
- **The Story Behind "HowVaibhav":**
  > *“People often ask: ‘Why the name HowVaibhav?’ Because whether deploying distributed cloud backends at 3 AM or fine-tuning a display serif’s bezier tangent by 0.2 millimeters, the reaction from peers has always been: ‘Wait, how did you pull that off?’ ...Well. How? Vaibhav. ✦”*
- **Software & Creative Instruments Stack:**
  - Photoshop, Illustrator, InDesign, Figma, Premiere Pro, After Effects, Picsart, CapCut, Audition, and Blender with authentic branded SVG badges and subtle hover lift physics.

### 3. कला मंडल (Kala Mandal) — 35 Curated Graphic Design Exhibits (`ArtCirclesOrbit.jsx`)
A monumental rotational dual-orbit showcase presenting 35 original graphic design masterworks:
- **Design Orbit:** 35 authentic, high-resolution artwork plates spanning Surrealism, Cyber Brutalism, Kinetic Action Photography, Sacred Geometry, Typography Systems, and Cultural Heritage.
- **Explanation Orbit:** Deep curatorial rationale, conceptual headlines, visual language breakdowns, and technical specifications (Lighting Kelvin, Pantone color codes, camera focal length, and compositional rules).
- **Curatorial Lightbox Modal:** Full-bleed inspection modal with Indian architectural motifs (Torana brackets, Bindu core), high-resolution uncropped plate view, and direct keyboard `Escape` dismissal.

### 4. Kinetic Mixed-Media Dadaist Assembly (`MixedMediaAssembly.jsx`)
- **Scroll-Converging Kinetic Canvas:** 20 tactile collage pieces (torn kraft paper, holographic foil, halftone screenprints, typography stamps, mechanical aperture shards) dynamically converge toward a masterwork assemblage as the user scrolls.
- **Parallax Layering:** Multi-depth physics where each element reacts at independent velocity and rotational offsets.
- **Curatorial Dossier Modal:** Deep-dive modal revealing complete artwork provenance, medium descriptions, and design philosophy.

## 🔊 Procedural Web Audio Engine (`soundFX.js`)

Unlike portfolios relying on bulky audio files that lag behind user input, this project synthesizes mechanical sound effects **procedurally in real time** via the Web Audio API:
- **Zero Network Overhead:** 0 KB audio files downloaded.
- **Zero Latency:** Instant acoustic feedback synchronized with pointer events.
- **Sound Palette:**
  - `playTick()`: Ultra-crisp high-frequency tick for letterform hover.
  - `playHover()`: Soft cyber tick for interactive buttons and orbit nodes.
  - `playSnap()`: Satisfying mechanical click for card drops and modal launches.
  - `playAperture()`: Shutter click for photo and dossier views.
  - `playPop()`: Soft tactile bubble pop for closing lightboxes.
  - `playWarp()`: Resonant low-pass cyber sweep for switching between Dev and Design modes.

## 🔍 SEO & Web Standards Compliance

The portfolio has been optimized for search discoverability, social sharing, and Core Web Vitals:
- **Semantic Heading Hierarchy:** Exactly one semantic `<h1>` on every page, with accessible labels for screen readers and search bots.
- **Schema.org Knowledge Graph (JSON-LD):** Rich structured data representing `Person` (Vaibhav Tiwari), `WebSite`, `WebPage` (Dev & Design), `ItemList` (Software Projects), and `CreativeWorkSeries` (Kala Mandal 35 Exhibits).
- **Dynamic Route Metadata:** `document.title`, `meta[name="description"]`, `link[rel="canonical"]`, and Open Graph tags dynamically update on route transitions in the React SPA.
- **XML Sitemap:** Verified [`sitemap.xml`](frontend/public/sitemap.xml) including both `https://www.howvaibhav.in/` and `https://www.howvaibhav.in/design`.
- **Descriptive Alt Attributes:** 100% of images and artwork plates carry descriptive, keyword-rich `alt` text.
- **Zero Broken Preloads:** Cleaned up critical rendering path asset preloads with `fetchpriority="high"`.

## 🚀 Quick Start

### Prerequisites
- **Node.js:** v18.0.0 or higher
- **npm:** v9.0.0 or higher

### Installation
```bash
git clone https://github.com/how-vaibhav/Portfolio.git
cd Portfolio
npm install
```

### Running Locally
To launch both frontend and backend concurrently:
```bash
npm run dev
```

| Service | Local Endpoint | Description |
| :--- | :--- | :--- |
| **Developer Mode** | `http://localhost:5173/` | CS & Software Engineering Portfolio |
| **Design Mode** | `http://localhost:5173/design` | Brand Identity & Typography Atelier |
| **Backend API** | `http://localhost:5001/` | Express REST Service |

To launch services independently:
```bash
npm run dev:frontend   # Frontend only (Vite)
npm run dev:backend    # Backend only (Node/Express)
```

### Production Build
```bash
npm run build
```
Generates a minified production build in `frontend/dist/`.
